# Lumen Garden Design Direction

## Surface
**Operate** first, **Explore** second. Users should immediately see what can be captured, moved, connected, or focused. The constellation is a working map, not decorative wallpaper.

## Composition
- Left rail: garden navigation and beds.
- Main field: context-dependent work surface (inbox, constellation, focus, review).
- Context inspector: selected seed/bed details on wide screens; bottom sheet or inline drawer on small screens.
- Persistent quick-capture affordance and keyboard command palette.

## Tokens
- Background: near-black warm ink or bone paper depending on theme.
- Surfaces: subtle tonal separation, mostly borders rather than floating cards.
- Accent: mineral teal.
- Supporting: pollen gold, clay coral, moss only where semantically useful.
- Radii: modest and systematic; avoid pill overload.
- Motion: short, physical, state-explaining; honor reduced motion.
- Type: chosen humanist sans for UI with a restrained serif accent only where it communicates reflection, not decoration.

## Interaction posture
- Fast capture, forgiving organization.
- Selection state must remain obvious.
- Empty states include one clear action.
- Drag-and-drop can enhance but never replace keyboard/button paths.
- Network is never required.

## Anti-slop gate
Reject: tech gradients, glass panels, three-card feature grids, fake streaks/scores, giant decorative numbers, rainbow bed colors, unlabelled icon buttons, centered dashboard composition, or plant emoji as the primary visual language.
